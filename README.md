# Описание проекта
Универсальный модуль, который можно добавить к любому проекту для ознакомления пользователей со страницей. При запуске продукт тура остальная часть страницы становится не кликабельной. Пользователь сможет взаимодействовать только с элементами внутри попапа.Присутствует скролл к элементам на странице, но не бездумный - для определения необходимости проскролливания есть функция, которая вычисляет, находится ли элемент в зоне видимости или нет.

# Технологии
- react
- typescript
- floating-ui
- zustand
- vite

# Как запустить
- git clone https://github.com/madama-drama/product-tour (копирование)
- npm install (установка зависимостей)
- npm run dev (запуск приложения)
